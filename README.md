## 🔗 Catch the good links

Save useful links without breaking your browsing flow. Open the on-page MagnoGrabr panel and pick your move:

| Tool | What it does |
| --- | --- |
| 🧲 **Grab** | Tap links to save them as you browse |
| ✏️ **Draw** | Sweep over a group of links to capture them together |
| ✨ **Smart Grab** | Find similar links, review the matches, then save |
| 🔗 **Extract page** | Collect links from the current page in one go |

The panel stays tucked away until you need it. Page tools can be switched off any time.

## 🗂️ Your links, sorted

- 🔎 Search URLs, link text, filenames, and source pages
- 🏷️ Filter by category; sort by newest, oldest, or name
- ☑️ Select links for bulk copy, export, or removal
- 📝 View details and recategorize links
- 🧹 Remove duplicates or clear out the collection
- 📋 Copy one link, selected links, or everything
- 📦 Export as plain text, CSV, or JSON
- 📏 Preview file size and filename when the server provides them

## 🎛️ Make it yours

🌗 Dark or light appearance · 🎨 Red, pink, or blue accent · 📤 Default export format · ⏱️ Optional capture delay

## 🔐 Private by design

Your collection and preferences stay in your Firefox profile. Page access powers the capture tools. For size and filename previews, MagnoGrabr may send a lightweight `HEAD` request directly to a captured link’s server—your collection is not sent to a separate service. No account needed.

## 🖥️ Part of the MagnoGrabr family
